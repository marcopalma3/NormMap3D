# NormMap3D
Smooth normative brain mapping of 3-dimensional morphometry imaging data using skew-normal regression.

This repository contains the accompanying code for the manuscript "Smooth normative brain mapping of 3-dimensional morphometry imaging data using skew-normal regression" by Palma et al. (2025), published on Human Brain Mapping:  	
https://doi.org/10.1002/hbm.70185. The vignette is available at https://marcopalma3.github.io/NormMap3D/NormMap3D_vignette.html.
