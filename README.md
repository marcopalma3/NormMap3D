# NormMap3D
Smooth normative brain mapping of 3-dimensional morphometry imaging data using skew-normal regression.

This repository contains the accompanying code for the manuscript "Skewed normative brain mapping of 3-dimensional morphometry imaging data using skew-normal regression" by Palma et al. (2024), available as a preprint on arxiv:  	
https://doi.org/10.48550/arXiv.2407.05806. The vignette is available at https://marcopalma3.github.io/NormMap3D/NormMap3D_vignette.html.
